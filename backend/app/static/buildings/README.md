# รูปตึก (Building Photos)

วางไฟล์รูปตึกไว้ในโฟลเดอร์นี้ แล้วอัปเดตฟิลด์ `image_url` ของตึกนั้นในฐานข้อมูล
ให้ชี้มาที่ไฟล์ -- backend เสิร์ฟโฟลเดอร์นี้ผ่าน `GET /static/buildings/<ไฟล์>` ให้อัตโนมัติ

## วิธีเพิ่มรูป

1. เตรียมไฟล์รูป (jpg/png) ตั้งชื่อตามรหัสตึก เช่น `105.jpg` สำหรับตึกรหัส `105`
2. คัดลอกไฟล์มาไว้ในโฟลเดอร์นี้ (`backend/app/static/buildings/`)
3. อัปเดต `image_url` ของตึกนั้นในฐานข้อมูลให้เป็น `/static/buildings/105.jpg`
   (แก้ตรง ๆ ในฐานข้อมูล หรือเพิ่มใน `backend/app/seed.py` แล้วรัน `python -m app.seed`)
4. รีเฟรชหน้าเว็บ -- ไม่ต้อง restart backend เพราะเสิร์ฟไฟล์สดจากดิสก์ทุกครั้ง

ถ้าตึกไหนยังไม่มี `image_url` หน้าจอจะแสดงไอคอนตึกแบบ placeholder แทนโดยอัตโนมัติ
ไม่มี error
